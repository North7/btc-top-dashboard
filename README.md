# Tidemark · BTC 週期訊號

比特幣週期像潮汐：頂部是滿潮、底部是退潮。Tidemark 每天標出這兩種水位訊號。


每天自動抓取 BTC 的公開市場數據（鏈上、資金流、衍生品、情緒、礦工），計算**頂部訊號 = 熱度 × 時機**與**底部訊號 = 冷度 × 底部時機**。
用途是在 2028 年減半後的週期（預期頂部 2029–2030）辨識頂部區。**僅供參考，不構成投資建議，不含任何交易功能。**

- 儀表板：`https://north7.github.io/tidemark/`
- 當日數據：`https://north7.github.io/tidemark/latest.json`
- 英文版：`https://north7.github.io/tidemark/en/`（首次依瀏覽器語言自動選擇，右上角可切換）

## 三個數字

| 數字 | 範圍 | 回答的問題 |
|---|---|---|
| **頂部訊號** `top_signal` | 0–100 | 主要數字 = 熱度（7 日均）× 時機 ÷ 100。≥ 50 頂部窗口、≥ 70 高度警戒 |
| **熱度** `heat_score` | 0–100 | 市場現在有多熱？四類指標加權平均。冷 < 40 ≤ 溫 < 65 ≤ 熱 |
| **時機** `timing_score` | 0–100 | 時間上像不像週期頂部？距減半天數＋距本輪低點天數 |
| **底部訊號** `bottom_signal` | 0–100 | 冷度 × 底部時機（見下方「底部訊號」） |

### 為什麼是「熱度 × 時機」

只看熱度時，週期中段的高點（2021-04、2024-03）熱度其實比真正的週期頂部（2021-11、2025-10）還高；
最終頂部常常是「價格新高、但估值與情緒指標較低」的頂背離。最終頂部的共同特徵是時間點很規律：

| 頂部 | 距減半天數 | 距前一個週期低點天數 |
|---|---|---|
| 2013-12 | 371 | 747 |
| 2017-12 | 525 | 1,067 |
| 2021-11 | 546 | 1,059 |
| 2025-10 | 534 | 1,062 |

回測（樣本內）結果：

| 週期頂部 | 頂部附近最高訊號 | 同輪其他時間最高 | 訊號首次 ≥ 50 |
|---|---|---|---|
| 2013-12 | 27 | 28 | 無（該輪較短，時間窗口未對上） |
| 2017-12 | 100 | 69 | 2017-08-05 |
| 2021-11 | 57 | 37 | 2021-10-16 |
| 2025-10 | 74 | 50 | 2025-07-07 |

中段高點的訊號：2013-04 為 0、2019-06 為 0、2021-04 為 34、2024-03 為 0。

## 底部訊號（2026-10 加入）

用途：參考並驗證週期結構，特別是「ETF 時代熊市是否變淺、本輪低點是否就是週期底部」。

**底部訊號 = 冷度（7 日均）× 底部時機 ÷ 100**；≥ 50 底部區、≥ 70 強烈底部。

| 部分 | 內容 | 權重 |
|---|---|---|
| 冷度・估值 | MVRV、NUPL：本輪預期底部 = 過去三次底部讀數擬合外推；中性 = 本輪預期底部與預期頂部的中點 | 50% |
| 冷度・礦工 | Puell（中性固定為 1.0，即收入等於年均）、Hash Ribbons（算力 30 日均 ÷ 60 日均，近 90 日最深投降，−5% 為滿分） | 30% |
| 冷度・價格結構 | AHR999（價格 ÷ 200 日幾何平均 × 價格 ÷ 長期指數成長估值；中性固定為慣用定投線 1.2）、Power Law（價格 ÷ 冪律趨勢價，趨勢線逐日只用當天以前資料擬合；中性為 1.0 倍），兩者平均 | 20% |
| 底部時機 | 距上次頂部天數（過去底部平均約 379 天）、距上次減半天數（約 859 天）；中心 ±60 天滿分，再往外 240 天降到 0 | — |

指標選擇依據（只看 2015、2018、2022 三次底部與 2019-12、2020-03、2021-07、2024-08 中段假底部）：
MVRV、NUPL、Puell 能清楚分開真假底部；恐懼貪婪、資金費率樣本太少；200 週均線與跌幅會被 2020-03 混淆；
Hash Ribbons 在減半後與政策事件也常投降，只作礦工輔助。
AHR999 加入後三次熊市底部訊號提高（68/95/79 → 73/95/83），假底部仍為 0，因此採用。
Power Law（冪律趨勢價倍數）：三次底部為 0.24、0.48、0.36 倍，加入後底部訊號 73/95/83 → 74/93/84，假底部仍為 0、熊市外 ≥ 50 仍為 0 天，
因此加入價格結構組。它與 AHR999 高度相關（對數相關 0.92），同組平均、不重複計分。頂部不採用：各輪頂部倍數 8.5→6.6→2.3→1.1 快速下降，
且 2021-04（3.1 倍）、2024-03（1.15 倍）中段高點不低於真頂部（2.3、1.1 倍），無法分辨最終頂部。
Pi Cycle Top（111 日均 ÷ 350 日均×2）經同樣方式測試：最近兩次頂部（2021-11、2025-10）比值僅 0.57，與 2019-06 假頂相同，
且曾在 2013-04、2021-04 假頂交叉；加入頂部訊號後 2021 頂部下降、窗外假訊號上升，因此未採用。

回測（樣本內）：三次熊市的底部訊號最高 74、93、84，四次假底部皆為 0，熊市以外從未 ≥ 50。

**本輪（樣本外，參數未參考 2026 年資料）**：2026-06-30 低點時底部訊號 58，本輪最高 59（2026-07-02，28 天 ≥ 50），
是四輪中最弱的一次。AHR999 在 6 月低點為 0.281，與過去底部（0.23–0.27）相當，Power Law 為 0.44 倍，也落在過去底部區間（0.24–0.48）；但估值面未出現投降
（本輪 MVRV 從未跌破 1，過去每次熊市都有 140–304 天）。可能的解釋是 ETF 時代高價買盤墊高了實現價格（平均成本）。
`latest.json` 的 `bottom.cycle_test` 會持續追蹤：若到底部時間窗口結束（目前為 2026-12-19）都未跌破本輪低點，
支持「本輪低點即週期底部、熊市變淺」；若出現更低的低點且 MVRV 跌破 1，則底部尚未出現。

限制：完整底部只有 3 次，樣本比頂部更少；若熊市結構真的變淺，估值冷度可能永遠達不到過去水準，訊號會偏弱。

## 週期策略（2026-10 加入）

「警戒 + 趨勢確認」（`btc_top/strategy.py`、`latest.json` 的 `strategy`、網站「週期策略」頁）：

| 狀態 | 條件 | 動作 |
|---|---|---|
| 持有中 | 頂部訊號 ≥ 50 或頂部時機 ≥ 50 | 進入警戒（保持到賣出） |
| 警戒中 | 週線 Supertrend（ATR 10 × 3）由多轉空 | 全部賣出 |
| 空手中 | 底部訊號 ≥ 50 或週線 Supertrend 由空轉多 | 全部買回 |

逐輪回測（每一輪只用當時已發生的頂部與底部設定參數，不偷看未來；手續費 0.1%、現金不計息）：

| 起點 | 策略 | 持有 | 策略／持有 | 策略最大回撤 | 持有最大回撤 |
|---|---|---|---|---|---|
| 2014 | 857× | 114× | 7.5× | −74% | −84% |
| 2016 | 643× | 197× | 3.3× | −74% | −84% |
| 2018 | 20.8× | 6.4× | 3.3× | −71% | −81% |
| 2020 | 24.6× | 12.0× | 2.1× | −66% | −77% |
| 2022 | 5.5× | 1.8× | 3.1× | −35% | −67% |

門檻 40／50／60 的 27 種組合在所有起點都勝過持有；手續費 0.5% 結果幾乎不變。
分批版（只作對照）：進入警戒先賣 1/3、週線轉空賣完。策略／持有為 2014 起 5.1×、2016 起 2.1×、2018 起 5.1×、2020 起 2.5×、2022 起 3.4×；
2017 那輪警戒來得太早（約 $1,059，比頂部早 10 個月），所以長期輸主策略，但最近三輪較佳、2020 起最大回撤 −54%（主策略 −66%）。
買回分批或保留 20–30% 底倉在所有起點都比主策略差，未採用。
限制：不是賣在頂部（過去賣出時已從頂部跌 26–65%，超額報酬主要來自避開熊市）；2021-05 曾誤賣一次；只有 4 次熊市可驗證；
若四年週期不再延續可能失效。模擬結果，僅供參考，不構成投資建議。

## 中期狀態（2026-10 加入）

獨立的「中期」分頁（不隨頂部／底部模式切換）幫助看清目前的市場狀態，**證據比頂部／底部訊號弱，只供參考**（`btc_top/midterm.py`、`latest.json` 的 `midterm`）。

| 區塊 | 內容 |
|---|---|
| 趨勢環境 | 價格相對 200 日均線、20 週均線（牛市支撐帶）、50 日均線 → 多頭趨勢／多頭回調／空頭反彈／空頭趨勢；週線 Supertrend（ATR 10 × 3，Bitstamp 日 K，只用已收完的週 K）方向與支撐／壓力位 |
| 牛市回調觀察 | 價格在 200 日均線之上時，日 RSI < 35、低於 50 日均線 10%、30 日跌逾 15%、恐懼貪婪 < 25、資金費率 ≤ 0，五項符合三項觸發 |
| 短線過熱 | 日 RSI > 75、高於 50 日均線 25%、30 日漲逾 40%、恐懼貪婪 > 80、資金費率為近一年前 10%，五項符合三項觸發；提示而非賣訊號 |

依據（2026-10 研究：48 個免費且可完整回測的指標，中期轉折以 ZigZag 20% 標記，2014–2019 觀察、2020–2026 檢驗）：
- 週期級：沒有新指標能把最終頂部排在中段高點之上，現行「熱度 × 時機」結構不變。
- 中期頂部：單一過熱指標之後 90 天報酬平均仍高於一般（動能延續）；組合過熱之後好壞參半，大跌機率只比一般略高，都不是可靠的賣訊號。
- 中期底部：牛市中的超賣組合有小幅優勢（檢驗期 90 天中位 +14%、一般 +7%），但只有 4–5 次；熊市中的超賣不可靠。
- Supertrend：週線一年約翻轉一次、30 天內很少來回，但屬確認型（翻空時距中期高點中位約 7 週、已跌約 35%）；日線每年翻轉 7–9 次、近半在 30 天內翻回，回測輸給持有。
- 未能測試（無免費完整歷史）：長短期持有者成本、SOPR、Reserve Risk、RHODL、選擇權、清算；總經數據待測。
門檻採常見慣例值、未針對歷史最佳化。頁面上的歷史統計（觸發次數、之後報酬）每天依最新數據重算。

## 計分方法

### 熱度

同類指標先平均成類別分數，再按權重加總（無資料的類別權重按比例分給其他類），限制在 0–100。

1. **週期法**：週期頂部為 2013-12、2017-12、2021-11、2025-10 各月最高收盤日，底部為兩頂之間最低收盤日。
   對各次頂部當日的指標值做對數線性擬合（含負值時改線性），外推本輪預期頂部值；底部同理推得下界。
   分數 = (當前值 − 下界) ÷ (預期頂部 − 下界) × 100，下限 0。
2. **百分位法**：歷史不足 3 個週期，或擬合出的預期頂部 ≤ 下界時，用自身過去 4 年的滾動百分位，
   並中心化：百分位 ≤ 35 為 0 分、100 為 100 分（避免平常狀態被算成「半熱」）。少於 90 天資料不計分。
3. 加總時單一指標分數上限 120。

### 時機

- 距減半天數：最近一次減半至今。
- 距本輪週期低點天數：上一個頂部之後的最低收盤日至今（逐日累計，只用當時已知的資料；再創新低時會重新計算）。
- 兩者各以**最近 3 次頂部的平均天數**為中心（目前約 535 天、1,063 天），中心 ±60 天滿分，再往外 240 天線性降到 0，取平均。
- 本輪預估：依 2028-04 減半（估計）推算的滿分窗口約 2029-08 ～ 2029-12；依本輪低點推算的窗口會隨低點移動，詳見 `latest.json` 的 `timing`。

### 持有者行為為何在公開版不計分

**長期持有者供給變化、LTH-SOPR、CDD / Dormancy** 沒有可公開使用的免費來源：
- BGeometrics 免費 API 有這些指標，但只提供近 4 年資料，且條款禁止把資料再散布給終端使用者（本倉庫與頁面公開）。
  2026-10 曾在本機試算：只涵蓋 2025 一次頂部，持有者分數在 2024-03 中段高點為 100、2025-10 真頂部只有 48，
  反而讓 2025 頂部當天的頂部訊號從 61 降到 57，因此不採用（本機私人版已移除）。
- 以 Coin Metrics 交易所流量替代已測試並**移除**：交易所淨流入在 2013、2017 頂部很高，但在 2021、2025 頂部為 0（資金改經 ETF、託管與 OTC），
  計入後會讓 2021 頂部訊號從 57 降到 49（未觸發頂部窗口）。

因此公開版的持有者類別標記為 `unavailable`，頁面不顯示，20% 權重按比例分給其他四類。

付費選項（v2，金鑰放 GitHub Secrets）：
- **Glassnode**（Professional 方案 API：LTH Supply、LTH-SOPR、CDD、Dormancy）
- **CryptoQuant**（SOPR、CDD、交易所流量；需確認 API 可回溯的歷史長度與公開顯示授權，Advanced 方案 API 約只回溯 1 年）
- **BGeometrics Professional**（含公開再散布授權）

### 已知限制

- 時機假設約四年的週期會延續。若週期變長或變短，頂部訊號可能提早、延後或整輪不亮；請同時看熱度與時機。
- 訊號是數個月的窗口，不是精確的頂部日期。
- 2013 年那一輪較短，用最近三輪設定的時間窗口抓不到。
- 歷史分數以目前參數計算（樣本內），過去只有 4 次頂部可驗證；回測時需注意。
- 對數線性外推會讓本輪預期頂部值偏低（例如 MVRV Z 約 1.7），鏈上估值類在中段行情就可能偏高。

## 輸出檔案

| 檔案 | 內容 |
|---|---|
| `docs/latest.json` | 頂部訊號、熱度、時機、zone、各類別與指標的數值和分數、預估窗口、stale / unavailable 標記 |
| `docs/index.html` | 手機版儀表板（靜態、資料內嵌，瀏覽器不呼叫外部 API） |
| `data/raw/*.csv` | 各資料源原始歷史（每日合併更新） |
| `data/indicators.csv` | 各指標每日數值 |
| `data/scores.csv` | 每日頂部訊號、熱度、時機、類別與指標分數（2011 年起） |

`zone`：頂部訊號 ≥ 50 為 `top_zone`；否則依熱度 `cold` < 40 ≤ `warm` < 65 ≤ `hot`。`composite_score` 與 `heat_score` 同值（相容舊欄位）。

## 運作方式

- GitHub Actions 每天 UTC 00:15 執行 `run.py`，完成後自動 commit `data/` 與 `docs/`。
- 任一資料源失敗時沿用前一次的資料，並在 JSON 標記 `stale: true`，不讓整個流程失敗。
- GitHub Pages 從 main 分支的 `/docs` 發布。

本機執行：

```bash
python3.11 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python run.py
```

## 公開倉庫規則

本倉庫只放公開市場數據與程式。**禁止寫入任何個人持倉、資產、成本或個人買賣決定。**
通用的「週期策略」規則與回測結果經同意公開，不含任何個人資訊。不使用任何交易所的交易 API 金鑰。
